## 🔬 项目概述

本项目实现了一个端到端的机器学习解决方案，用于预测静电纺纳米纤维的平均直径。主要技术特点包括：

- **分子指纹编码**：使用 RDKit 将材料 SMILES 编码转换为 Morgan 指纹
- **PCA 降维**：将高维分子特征降维至主成分
- **多模型对比**：XGBoost、随机森林、梯度提升和 SVR
- **LOFO 敏感性分析**：评估各特征对模型预测的贡献度
- **机理解析**：关联分子描述符与主成分，揭示影响机制

## ✨ 功能特性

- **数据预处理**：自动处理缺失值、范围解析和异常值检测
- **特征工程**：生成 2048 位 Morgan 指纹并结合 PCA 降维
- **模型训练**：使用 GridSearchCV 进行超参数优化，5 折交叉验证
- **模型评估**：全面的评价指标（R²、MAE）和稳定性分析
- **机理解释**：关键主成分的化学亚结构溯源分析

## 🛠️ 安装说明

### 环境要求

- **Python 3.10 或更高版本**（已在 Python 3.10.11 上测试）
- [RDKit](https://www.rdkit.org/)（用于分子指纹生成）

> ⚠️ **注意**：Python 3.12+ 可能与部分科学计算包存在兼容性问题，建议使用 Python 3.10 或 3.11。

### 安装步骤

1. 克隆仓库：
```bash
git clone https://github.com/yourusername/electrospun-nanofiber-prediction.git
cd electrospun-nanofiber-prediction
```

2. 创建虚拟环境（推荐）：
```bash
python -m venv venv
# Windows:
venv\Scripts\activate
# Linux/Mac:
source venv/bin/activate
```

3. 安装依赖：
```bash
pip install -r requirements.txt
```

**注意**：如果通过 pip 安装 RDKit 遇到问题，建议使用 conda：
```bash
conda install -c conda-forge rdkit
```

## 📊 实验结果

### 主要发现

- **最优模型性能**  
  随机森林（Random Forest）在五折交叉验证中达到 **R² = 0.916 ± 0.03**，平均绝对误差 **MAE = 242.44 nm**；XGBoost（R² = 0.912）与梯度提升回归（R² = 0.909）性能相近，显著优于支持向量回归（R² = 0.774）。

- **异常值清洗增益**  
  基于残差统计的 **3σ 准则**剔除 27 个异常样本（约 1.6%），使集成模型的 R² 从约 0.78 跃升至 0.91，MAE 降低约 **30%**。

- **关键工艺变量识别**  
  LOFO 敏感性分析表明，**溶液浓度**是主导纤维直径的一阶变量（ΔMAE = 52.85 nm），**流速**（19.25 nm）与**高湿度**（16.78 nm）为次级控制因素，而距离、温度、电压贡献相对均衡（ΔMAE 6.5–9.0 nm）。

- **分子指纹降维有效性**  
  2048 位 Morgan 指纹经 PCA 压缩至 **15 个主成分**（累计方差解释率 **95%**），既降低了过拟合风险，又保留了化学结构的关键拓扑信息。

- **物理可解释性突破**  
  载荷分析将主成分（PC_6、PC_11、PC_12、PC_14）溯源于**极性官能团密度、脂肪族链段长度、卤素取代类型及侧链乙酰化修饰**，验证了微观结构通过影响介电常数与电荷承载能力来调控纤维直径的物理耦合机制。


## 📈 数据说明

### 输入特征

| 特征类别 | 特征名称 | 单位 | 说明 |
|:---|:---|:---|:---|
| **工艺参数** | Flow rate | ml/h | 溶液流速 |
| | Tip distance | cm | 针尖至收集器距离 |
| | Voltage | kV | 施加电压 |
| | Concentration | w/w% | 聚合物质量分数 |
| | Temperature | ℃ | 环境温度 |
| **分类编码** | Humidity_Medium | - | 相对湿度 33.3%–66.6%（哑变量） |
| | Humidity_High | - | 相对湿度 >66.6%（哑变量） |
| | Humidity_Missing | - | 湿度数据缺失（哑变量） |
| | CV_Medium | - | 变异系数 33.3%–66.6%（哑变量） |
| | CV_High | - | 变异系数 >66.6%（哑变量） |
| | CV_Missing | - | 变异系数缺失（哑变量） |
| **分子结构** | PC_1 – PC_15 | - | Morgan指纹经PCA降维得到的15个主成分 |

### 目标变量

- **AVG Nanofiber diameter [nm]**：静电纺纳米纤维平均直径

- **原始样本**：1,977 条
- **清洗后**：1,667 条
- **剔除异常值后**：1,640 条
- **覆盖材料**：29 种聚合物类型
